[Compare app-owned tenants with Keycloak Organizations.]
Keycloak Organizations
Keycloak Organizations can model B2B organizations, invitations, organization identity providers, and organization claims. It is useful as a later experiment, but it does not replace TenantId data isolation in the Note database. Keycloak Organizations
I would compare it only after app-owned tenancy works.
Avoid realm-per-tenant initially. It would require multiple trusted authorities, client registrations, secrets, callback configurations, signing-key sets, and issuer-aware logout validation. Use it only when tenants genuinely require separate credential policy, administrators, identity providers, or regulatory isolation.
